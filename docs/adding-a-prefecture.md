# 都道府県を追加する手順

全国版は、都道府県ごとにこの手順で収録を広げていく。1 回の作業で 2〜3 県が目安。
**正確さがこのサイトの価値なので、速さより確認を優先する。**

## 0. 前提
- 使う情報は、国・都道府県・市町村・港湾管理者・その運営団体が公表しているものだけ。ブログ、まとめサイト、投稿、AI の回答は使わない（手がかりとして探すのはよいが、出典にはしない）。
- 公式の文章・地図画像・PDF は転載しない。事実だけを自分の言葉で書き、原典にリンクする。
- 作業前に `git pull` する（週次チェックが自動でコミットするため）。

## 1. 公式ルールの索引（data/sources.json）
各都道府県で、次を探して `links` に入れる。見つからないものは無理に埋めず、`memo` に「見つからず」と書く。

| 探すもの | よくある場所・名前 | kind |
| --- | --- | --- |
| 海での釣り（遊漁）のルール | 県の水産課「遊漁者の皆様へ」「海面における遊漁のルール」 | 海 |
| 海区漁業調整委員会の指示（まき餌の禁止など） | 県の水産課、委員会のページ。**有効期限を `valid_until` に必ず書く** | 海 |
| 川・湖のルール、漁協の遊漁規則 | 県の水産課・内水面の担当、内水面漁場管理委員会 | 川・湖 |
| 港の釣り禁止・立入禁止、釣り可能区域 | 県の港湾課・港湾事務所、市の港湾部局 | 港 |
| 漁業調整規則の本文（解説ページが無い場合のみ） | 県の例規集・水産課 | 海・川 |

## 2. 公式に釣りができる場所（data/spots.geojson）
探す順番:
1. 国交省「港湾における釣り施設一覧」と「釣り文化振興モデル港」に載っている、その県の港
2. 県・市町村が運営・案内している海釣り公園、釣り桟橋、開放防波堤
3. 漁港の釣り開放（市町村・漁協が公表しているもの）

各場所で確認すること:
- 管理者が「釣りをしてよい」とはっきり書いているか。書いていなければ載せない。
- 状態 `status`: 常設なら `open`、日を限った開放なら `limited`、今年の開放が確認できなければ `unconfirmed`。
- 時間・料金・条件。公式に書いていなければ「公式ページに記載なし」と書く（推測で埋めない）。古い資料の値を使うときは「2020 年の発表では」のように年を書く。
- 位置: 公式ページに地点があれば `point`。無ければ地区の代表点（`district`）か港のおおよその場所（`port`）にし、`position.note` にそう書く。
  - 地区の代表点は国土地理院の住所検索で得られる（`https://msearch.gsi.go.jp/address-search/AddressSearch?q=<住所>`）。
  - 座標は **[経度, 緯度]** の順。
- 出典ごとに `published`（ページの掲載日。無ければ null）、`checked`（確認した日）、`checked_how`（開いて読んだら `page`）。

## 3. 確認と書き出し
```powershell
python scripts/validate_data.py
```
```powershell
python scripts/build_static.py
```
`pref/<slug>.html` が自動で作られ、トップページの「収録状況」とサイトマップも更新される。

## 4. 見た目の確認
```powershell
python -m http.server 8765 --bind 127.0.0.1
```
http://localhost:8765/?pref=<slug> を開き、地図の点・一覧・出典リンクを確かめる。

## 5. 公開
コミットして push する。GitHub の `validate` が通ることを確認する。
次の週次チェックで、新しく足した出典の本文が保存され、それ以降の変化が見張られる。

## 週次チェックの Issue が来たら
- 差分を見て、メニューの変化など中身に関係なければ Issue を閉じる。
- 中身が変わっていたら原文を読み、データを直して `checked` を今日にする。「掲載日の修正案」が出ていれば `published` も直す。
- 「続けて開けなかった出典」は、移動先を探して URL を直す。見つからなければその出典を外し、場所の状態を見直す。
